## 1920×1080 布局

- 弹窗中心：`(960, 540)`。
- 完整资料框：原尺寸 `400×810`，范围 `x=760..1160`、`y=135..945`。
- 姓名牌：中心 `(960, 494)`，保持原尺寸 `342×39`。
- 资料区：境界/性别与宗门/身份按两列两行排列；`1×65` 分隔线位于弹窗横向正中，禁止拉伸。
- 属性底板：中心 `(960, 696)`，保持 `310×110` 原尺寸；属性名称与金色数值分列显示。
- 左右按钮：中心 `(874, 796)`、`(1046, 796)`；通栏按钮中心 `(960, 858)`。
- 所有文字和立绘都属于弹窗内部内容，不改变外部 HUD。
