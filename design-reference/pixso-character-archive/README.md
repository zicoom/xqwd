## 代码边界

- `src/ui/save/CharacterArchiveView.js` 只负责素材预加载、绘制、悬浮状态、点击转发和头像圆形裁切。
- `src/scenes/SaveSlotScene.js` 只装配 `GameState` 的已有档位操作与场景跳转。
- 创建、读取、删除存档的规则和存档结构没有写入 UI，也没有因效果图新增任何档位数据。
