## 交互与代码边界

- 五行区域按当前 Pixso 的统一加减按钮实现：先点选一项灵根，再点击减号或加号。
- `src/ui/character/CharacterCreateView.js` 只负责素材预加载、绘制、选中态、悬浮反馈和点击转发。
- `src/scenes/CharacterCreateScene.js` 只负责 Phaser 生命周期、视图装配、立绘选择层和场景跳转。
- 道号、性别与立绘同步、五行 10 点分配、初始技能和确认创建规则仍由
  `src/domain/character/CharacterCreationService.js` 负责，本轮没有改动存档结构或玩法数值。
