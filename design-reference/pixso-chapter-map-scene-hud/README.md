## 交互与代码边界

- `src/ui/ChapterMapHud.js` 只负责场景 HUD 素材预加载、绘制、输入命中与用户反馈。
- `src/ui/PlayerTopToolbar.js` 保持为共享顶部工具栏；第一章大地图不覆盖其角色状态底板，也不改变任何坐标和入口路由。
- `src/scenes/VillageScene.js` 只在 Phaser `preload()` 中装配场景 HUD 素材。
- 任务规则、NPC 资料、存档和地图移动仍由原有领域与场景服务负责；本轮没有在 UI 中新增玩法或存档规则。
