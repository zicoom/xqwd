## 1920×1080 布局

- 对话框左上角：`(500, 694)`，保持 `978×386` 原始尺寸，底部流苏落在画布底边。
- NPC 立绘基准：脚底中心 `(590, 760)`，在 `260×360` 范围内等比缩放，宣纸框覆盖立绘下缘。
- NPC 姓名牌显示为 `100×43`，中心位于 `(636, 598)`；主角发言时使用 `(1370, 598)`。
- 正文换行宽度限制为 `850px`，字号 `20px`；使用高级换行将连续中文按字符折行，长台词不会越过右侧安全边界。
