## 职责边界

- `src/ui/cover/CoverView.js`：素材预加载、坐标绘制、悬浮反馈和点击转发。
- `src/scenes/CoverScene.js`：场景生命周期、进入档案页、打开设置、进入开发者控制台和刷新恢复。
- 封面 UI 不读取或修改角色档案，也不实现存档迁移。

没有伪造 D2C 输出，也没有修改 Pixso 文件。
