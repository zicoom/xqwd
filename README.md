# 玄穹问道 · 第一章原型

这是基于 **HTML + JavaScript + Phaser.js** 制作的可运行网页游戏原型。

## 已完成流程

角色创建（名字、性别、五行 10 点分配）→ 栖霞村自由移动 → 发现古玉 → 回合制战斗 → 第一章结算。

## 启动方法

不要直接双击 `index.html`，也不要使用普通静态服务器。物品、NPC、建筑和地图编辑器需要
项目自带的本地数据接口；请双击根目录的 `启动游戏.bat`，或在项目目录运行：

```powershell
node server.cjs
```

然后在浏览器访问 `http://localhost:8000`。

## 操作

- 栖霞村：`WASD` / 方向键移动，鼠标点击自动前往。
- 古玉剧情：按空格键进入战斗。
- 战斗：`1` 初始五行术法，`2` 普通攻击，`3` 防御并恢复少量灵气。
